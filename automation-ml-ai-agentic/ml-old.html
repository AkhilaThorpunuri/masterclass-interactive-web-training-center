PILLAR 02

Machine Learning: rules learned from data

Instead of programming “if X then Y”, we show the computer thousands of examples and let an algorithm discover the pattern. The output is a model — a function that makes predictions on data it has never seen.

TRADITIONAL PROGRAMMING
Data + Rules → Answers
⇄
MACHINE LEARNING
Data + Answers → Rules (model)
01 · FLAVOURS

Types of machine learning

Learn from labeled examples

Each training example has the right answer attached (“spam / not spam”, “price = $412k”). The model learns to map inputs to labels.

Classification predicts categories; regression predicts numbers.

Logistic regressionRandom forestXGBoostNeural nets

EXAMPLES

📧 Spam filtering · 🏦 Credit scoring · 🩻 Tumor detection · 🏠 House-price prediction · 📦 Demand forecasting

Find hidden structure

No labels — the algorithm groups similar items, compresses dimensions or flags outliers on its own.

K-meansDBSCANPCAAutoencoders

EXAMPLES

🛍️ Customer segmentation · 🔍 Anomaly / fraud detection · 🧬 Gene clustering · 📰 Topic discovery

Learn by trial and reward

An agent takes actions in an environment and receives rewards. Over many episodes it learns a policy that maximizes long-term reward — the ancestor of today’s agentic systems.

Q-learningPPORLHF

EXAMPLES

♟️ AlphaGo · 🤖 Robot locomotion · ⚡ Data-center cooling · 💬 Aligning LLMs with human feedback

Labels from the data itself

Hide part of the input and predict it: the next word, a masked patch of an image. This scales to internet-sized data and powers foundation models.

Next-token predictionMasked modelingContrastive (CLIP)

EXAMPLES

🧠 GPT / Gemini / Claude pre-training · 🖼️ Image embeddings · 🔊 Speech models
